Functional Power with Effect-ts

Logic Flow

Effect Generators

Complex backend operations are wrapped in Effect.gen, providing a clean syntax for async flows and dependency management. 

export const getUser = (ctx, clerkId) =>
  Effect.gen(function* () {
    return yield* Effect.promise(() => 
      ctx.db.query('users')...
    );
  });
Error Handling

Tagged Error Classes

Errors are first-class citizens. Using Schema.TaggedErrorClass, we define semantic errors that are propagated safely to the frontend. 

export class Unauthorized extends Schema.TaggedErrorClass...
export class NotFound extends Schema.TaggedErrorClass...

Architecture Note: runEffect

The convex/effect.ts utility provides runEffect, which executes effects and converts failures into ConvexError by encoding the TaggedError into a schema-validated object. This ensures the frontend receives structured error data instead of generic strings.

Type-Safe Validation with Zod

Frontend

PromptForm Validation

Nested validation for dynamic variables and prompt content ensures data integrity before it even hits the backend. 

const promptFormSchema = z.object({
  title: z.string().min(1),
  variables: z.array(z.object({
    name: z.string(),
    type: z.enum(['text', 'choices'...])
  }))
});
Backend

Convex Validators

While the frontend uses Zod, the backend mirrors this via Convex's v values in convex/validators.ts for strict RPC protection. 

export const promptArgsValidator = {
  title: v.string(),
  isTemplate: v.boolean(),
  variables: promptVariablesValidator
};

Implementation: src/proxy.ts

Route Protection Logic

Promptamist uses a createRouteMatcher pattern to define public access. All other routes are protected by auth.protect(), redirecting unauthenticated users to sign-in. 

const isPublicRoute = createRouteMatcher([
  '/', '/pricing', '/p/(.*)', // Public Access
  '/sign-in(.*)', '/api/webhooks(.*)'
]);

export default clerkMiddleware(async (auth, req) => {
  if (!isPublicRoute(req)) await auth.protect();
});
